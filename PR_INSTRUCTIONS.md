# How to Merge Latest Changes to Production Branch

## Via GitHub Web Interface:

1. Go to: https://github.com/robertjanji15-hash/JANTEC-ERP

2. Click "Pull requests" → "New pull request"

3. Set branches:
   - **Base**: `claude/investigate-code-comparison-011CULwSYGxJduTmXHkeLte8`
   - **Compare**: `claude/show-latest-project-011CUxqpJBRmcA5UPf7FjtvV`

4. Click "Create pull request"

5. Review changes and click "Merge pull request"
